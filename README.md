# WebApp

이 교과목은 모바일 웹 환경에서 동작하는 애플리케이션 구현에 대해 다룹니다. HTML, Javascript, CSS 및 서버 프로그램의 동작 원리와 구현 방법을 프로그래밍 실습을 병행하여 학습합니다. 이 교과목을 통해 모바일 환경을 고려한 웹
애플리케이션 구현 능력을 배양합니다(방학 때 특강 신청).

기초적인 프론트엔드 UI 구현(React SPA) 단계를 넘어, 실제 사용자가 이용할 수 있는 완성도 높은 프로덕션 수준의 웹 애플리케이션을 기획, 개발, 배포하는 실무 심화 과정입니다. 프론트엔드 컴포넌트 설계부터 클라우드 인프라 및 데이터 플랫폼 활용까지 전체 웹 서비스 생태계를 관통하는 역량 배양을 목표로 합니다.

주요 교육 및 응용 영역:

1. 모던 프론트엔드 심화 아키텍처
* React 아키텍처의 핵심인 가상 DOM 동작 원리 완벽 이해
* Hooks 및 컴포넌트 생명주기를 활용한 데이터 흐름 제어 및 성능 최적화
* `styled-components` 패턴을 적용한 유지보수 용이한 UI 컴포넌트 스타일링 및 다중 페이지 라우팅 환경 구축


2. 풀스택 웹 애플리케이션 프레임워크 연동
* 형상 관리 및 협업 워크플로우: GitHub을 통한 소스코드 버전 제어 시스템(VCS) 운영 및 지속적 통합 환경 모니터링
* 서버리스 백엔드 및 데이터베이스 통합: Supabase 등의 BaaS(Backend-as-a-Service) 인프라를 연동하여 관계형 데이터베이스 설계, 실시간 데이터 동기화, 사용자 인증(Authentication) 및 보안 규칙 적용
* **클라우드 빌드 및 고성능 배포:** Vercel 등의 호스팅 플랫폼을 활용하여 완성된 애플리케이션을 글로벌 에지 네트워크에 실시간으로 빌드하고 무중단 배포(CI/CD)하는 파이프라인 관리



**최종 교육 목표:**
단순한 화면 개발자에 머무르지 않고, [형상 관리(GitHub) ➔ 데이터베이스·인증 연동(Supabase) ➔ 클라우드 무중단 배포(Vercel)]로 연결되는 현대적인 웹 프로그래밍 개발 파이프라인의 전 과정을 주도적으로 구축하고 운영할 수 있는 실무형 풀스택 역량 확보.
